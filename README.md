# Weather App

## Project Description
This is a simple **Weather Application** built using **HTML, CSS, and JavaScript**.  
It allows users to search for any city and get **real-time weather details** such as:

- City name
- Temperature (in Celsius)
- Weather condition
- Weather icon

The app fetches live weather data from the **OpenWeatherMap API**.

---

## Technologies Used
- **HTML** – For structure of the web page  
- **CSS** – For styling and layout  
- **JavaScript** – For logic and API integration  
- **OpenWeatherMap API** – For fetching real-time weather data

## How It Works
1. The user enters a **city name** in the input box.
2. When the **Search** button is clicked:
   - JavaScript captures the city name.
   - A request is sent to the OpenWeatherMap API using `fetch()`.
3. The API returns weather data in **JSON format**.
4. The app displays:
   - City & country name
   - Temperature in °C
   - Weather description
   - Weather icon

---

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**  
   *(or simply double-click `index.html`)*.
5. Enter a city name and click **Search**.

## API Used
**OpenWeatherMap API**

https://api.openweathermap.org/data/2.5/weather


 **Note:**  
An API key is required.  
Replace the API key in `script.js` with your own API key if needed.
